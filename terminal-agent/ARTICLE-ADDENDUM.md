## 13. Собираем всё в терминальный чат

Три сборки помогли увидеть отдельные детали: что подтверждено, какое наблюдение получить и когда остановить исправление. Теперь ими можно пользоваться через обычный разговор. В каталоге `terminal-agent` есть отдельное приложение: вы пишете задачу, исполнитель работает с файлами, а терминал показывает происходящее по мере выполнения.

Запустите его из каталога `terminal-agent`:

```bash
./setup.sh
./jev
```

Первая команда создаёт виртуальное окружение и устанавливает зависимости интерфейса. Нужны Python 3.9+, macOS или Linux, авторизованный Codex CLI и ключ TypeSafe в `TYPESAFE_API_KEY`. Команда `./jev --doctor` проверяет готовность окружения без вызова моделей. Подробности настройки ключа есть в `README.md` рядом с приложением.

Откроется пустой чат. Агент ждёт вашего сообщения; при запуске задача автоматически не отправляется. Например, введите такой запрос и нажмите Enter:

> Создай CLI-анализатор инцидентов на Python без внешних библиотек. Он читает JSONL, группирует ошибки по сервисам, убирает дубли event_id, правильно сравнивает часовые пояса и пропускает битые строки. Добавь пример связанных сбоев и ложный след. Сохраняй JSON- и Markdown-отчёт с event_id, отделяй гипотезу о причине от доказанных фактов. Напиши и запусти unittest-тесты, выполни CLI на примере. В конце дай команду запуска. Создай файлы в текущей папке.

Это уже задача на несколько файлов: парсер, обработка данных, интерфейс командной строки, отчёт и тесты. Её результат можно открыть и запустить самостоятельно. Текст не выбирает заранее записанный сценарий: именно ваш запрос получает исполнитель.

### Кто сейчас работает

В начале **Jev** отвечает на Choice: нужен ли режим изменения файлов, исследование проекта или разговорный ответ. **Codex** читает материалы, пишет код, выполняет команды и формулирует ответ. **Harness** запускает проверки, сохраняет результаты и ограничивает продолжение. После попытки Jev предлагает завершение, доработку или уточнение и отдельно оценивает соответствие работы запросу через Noul.

В терминале видна цепочка этапов:

```text
Ваш запрос → Jev route → Codex → Проверки → Jev review → Результат
                           ↑                    │
                           └──── доработка ─────┘
```

Узлы меняют состояние по фактическим событиям. В разговоре появляются команды и их вывод, справа — варианты Jev с вероятностями, проверки и изменённые файлы. Счётчики показывают вызовы и токены Jev и Codex отдельно. Если началась вторая попытка, это новый вызов исполнителя. Граф объясняет последовательность действий; скрытые рассуждения модели он не изображает.

### Что остаётся после ответа

Файлы создаются в рабочей папке, путь которой указан в шапке. Рядом сохраняется сессия:

```text
.sessions/<id>/
  workspace/        созданный проект
  session.json      история разговора
  events.jsonl      наблюдаемые события
  turn-001/         запрос, ответы моделей, проверки и result.json
  screenshots/      экраны, сохранённые через Ctrl+S
```

Статус «Результат подготовлен» означает, что исполнитель закончил работу; выполненные проверки перечислены отдельно. Его собственные тесты не становятся независимой приёмкой. «Проверки контракта пройдены» относится только к заранее зарегистрированному контракту и актуальной версии файлов. Провал проверки блокирует приёмку независимо от ответа Jev.

Теперь напишите: **«Добавь фильтр по сервису, сохрани прежний формат отчёта и проверь, что фильтрация не ломает дедупликацию»**. Следующий ход получает историю и работает в той же папке. Вернуться к ней после закрытия терминала можно командой:

```bash
./jev --resume last
```

Для своего проекта используйте `./jev --project /absolute/path/to/project`. Для отдельного упражнения с готовым внешним контрактом — `./jev --mission loglab`: команда создаст копию сломанного анализатора, а задание вы отправите сами. **F2** только вставляет пример в поле. **F3** открывает журнал, **Ctrl+C** останавливает текущую работу; уже внесённые изменения сохраняются. На выходе остаются проект, история решений и команды, по которым результат можно проверить.
