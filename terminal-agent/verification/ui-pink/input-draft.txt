Создай CLI Crypto Detective на Python без внешних библиотек.

Он читает CSV транзакций: tx_hash, timestamp,
from_address, to_address, token, amount.
Построй ASCII-граф, найди круговые переводы
и цепочки до трёх переходов.
Указывай конкретные tx_hash для каждого наблюдения.
Разные токены не складывай; суммы считай через Decimal.

Создай демонстрационные данные, Markdown- и JSON-отчёты.
Добавь тесты и реально запусти программу и проверки.
Отделяй наблюдаемые связи от гипотез.
В конце дай команду анализа моего CSV.
