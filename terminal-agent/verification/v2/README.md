# Проверки Jev Terminal v2 · 21 сентября 2026

Проверена собственная реализация Python/Textual. Исходники четырёх upstream
изучались отдельно; этот протокол не является заявлением о запуске их test suites.

## Автоматические проверки агента

**108 тестов проходят локально на Python 3.9.6.**
[Полный вывод](./unit-tests.txt), [машиночитаемый результат](./unit-tests.json).

Покрыты реальные дочерние процессы и их отмена, повторное выполнение проверок,
защита контракта, повреждённые журналы и незавершённые сессии, подбор контекста,
symlink и границы чтения, Noul-ранжирование, assist/observe/off, plan, повторная
попытка с новым контекстом, сохранение diff, экспорт и черновики. UI-тесты проверяют
многострочную вставку, отправку, 80×24, карточки tools, поиск, восстановление сессий,
просмотр файлов и отображение завершения/ошибок.

Модельные ответы в этих тестах намеренно подставлены. Выполнение subprocess и
терминальные события проверяются фактически. Вызовы API вынесены в живые прогоны
ниже, чтобы тесты читателя не требовали ключа и не расходовали лимиты.

## Живой Crypto Ledger

Сессия **20260921-003736-ab8721** запускалась через настоящий TUI в PTY. Запрос был
виден в редакторе до отправки; вызовы начались только после Ctrl+D.

В исходном учебном проекте проходил **1 из 7** тестов: [baseline](./crypto-baseline-tests.txt).
Контракт и его тесты написаны до вызова агента. Первый ход исправил Decimal,
комиссии, дубли, timezone и обработку невалидных строк, создал отчёт и отдельные
12 регрессионных тестов. Harness повторно запустил сохранённый контракт и получил
7 PASS на неизменённом снимке. Jev review предложил завершение, Python вернул
`accepted` с областью действия «только сохранённый контракт».

Первый ход занял **227.82 с**: 2 вызова Jev, 1 worker, 2 запуска команды контракта
(до и после работы). Во время этого прогона обнаружилось, что внешний `.gitignore`
для `.sessions/` исключал все файлы из нового retrieval. Codex продолжил читать
проект своими инструментами, но source-Noul в первом ходе не вызывался. Это
сохранено в исходном `context.json`; данные не заменены «успешным» повтором.

Граница Git-поиска исправлена и покрыта регрессией. Второй ход той же сессии через
новый процесс дополнил только README. Jev получил **5 реальных кандидатов** и
выбрал `README.md`, `report.json`, `ledger.py`. Сохранены реальные оценки, пути,
строки и SHA-256. Например, README получил Noul **0.86**, отчёт — **0.73**, ledger —
**0.46**. Это оценки релевантности этому запросу, не измерение правильности программы.

Второй ход занял **89.41 с**: 3 вызова Jev, 1 worker, 2 запуска контракта. Создан
настоящий diff README, повторная приёмка прошла. Новый раздел документации не
покрывается исходными семью тестами расчётов: его содержание дополнительно
просмотрено и сверено с данными отчёта.

## Сохранённые свидетельства

[Переносимая сессия](./crypto-live-session/) содержит историю, JSONL, реальные
request/response Jev, поток worker, результаты проверок, снимки и готовый workspace.
[Сводка двух ходов](./live-summary.json) сохраняет статусы, время и provider usage.
Счётчики токенов — данные провайдеров; из них не рассчитывалась цена.
В опубликованных текстовых журналах корень авторского checkout заменён на
`<checkout>`; код готового инструмента сохранён без переписывания.

Повторить готовый инструмент без моделей:

```bash
cd terminal-agent/verification/v2/crypto-live-session/workspace
python3 -B -m unittest discover -s tests -v
python3 -B -m unittest discover -s regression_tests -v
python3 -B cryptoledger.py examples/trades.csv --json report.json
```

Новый самостоятельный прогон агента: `./jev --mission cryptolab`, затем F2 и Ctrl+D.
Продолжать архивный workspace можно через `--resume` с его абсолютным путём;
для собственного опыта предпочтительна новая копия миссии.
