# Идея → вопросы → план → работа · 21 сентября 2026

Проверен настоящий терминальный интерфейс Python/Textual с Codex CLI и API
TypeSafe, модель Jev `jev-1.13.0`. Экраны сняты во время живого прогона через
Ctrl+S. PNG — браузерные снимки полученных SVG; это не макеты.

## Что ввели и что получили

Исходный запрос: **«Хочу что-нибудь полезное про крипту, чтобы запустить прямо
в терминале.»** Планировщик задал один вопрос: считать прибыль или вести портфель.
После явного выбора «Считать прибыль» и проверки ответа он составил план
терминального калькулятора одной покупки и продажи, с комиссиями и проверками.

Первая подготовка заняла **30.19 с**, вторая — **31.89 с**. Обе использовали
настоящий Codex в режиме чтения. До принятия плана рабочая папка оставалась пустой:
снимки до и после обеих подготовок совпадают, записанных файлов — **0**. На этой
стадии вызовов Jev — **0**. Сохранены исходные ответы и запросы в
[live-session/intake](./live-session/intake/).

Процесс был закрыт на готовом плане и запущен повторно с `--resume`. План
восстановился без начала работы. Затем была явно нажата кнопка «Начать работу».
Точный [согласованный запрос](./approved-request.md) совпадает с `text` в
[исполнительном request.json](./live-session/turn-003/request.json).

Исполнение заняло **140.20 с**: **2 вызова Jev, 1 вызов исполнителя**, затем
проверка созданных тестов. Пустой проект не требовал ранжирования исходников.
Jev route выбрал действие, Jev review предложил завершение. Worker создал
`crypto_profit.py`, `README.md`, `test_crypto_profit.py`.

Итог harness — **`ready` / «Результат подготовлен»**. Во время работы не было
заранее зарегистрированного независимого контракта, поэтому результат не выдан
за `accepted`. Собственные **9 тестов** исполнителя прошли. Полный журнал сохраняет
также неуспешную промежуточную команду worker; она не удалена из протокола.

## Независимая проверка результата

После окончания работы отдельный проверяющий запустил **47 сценариев через CLI**,
с ожидаемыми числами, заданными независимо от реализации. **47/47 прошли**:

- Без комиссий: покупка 2 × 100, продажа 2 × 120 → прибыль **40.00**, **20.00%**.
- По 1% на каждой операции → затраты **202.00**, поступления **237.60**, комиссии
  **4.40**, прибыль **35.60**, доходность **17.62%**.
- Убыток, нулевая прибыль, нулевая цена продажи, дробное количество, запятая,
  разные комиссии и допустимая комиссия 99.99%.
- 34 сценария ошибочного ввода с повторным запросом значения: строки, NaN,
  бесконечность, отрицательные значения, недопустимые нули и комиссии.
- EOF на каждом из пяти шагов ввода: понятная отмена без traceback.

Отдельно повторены **9/9 тестов**, созданных worker. Хеши всех трёх исходных файлов
не изменились. [Методика, harness и результаты](./independent/README.md).
Это проверка после прогона; она не меняет исторический статус живого запуска.

Повторить без ключей и моделей из `terminal-agent/`:

```bash
python3 verification/guided/live-session/workspace/crypto_profit.py
python3 -B verification/guided/independent/check_cli.py \
  verification/guided/live-session/workspace --output /tmp/jev-calculator-checks
```

## Проверки самого агента

**191 автоматический тест прошёл на Python 3.9.6.**
[Вывод](./unit-tests.txt), [метаданные запуска](./unit-tests.json).
Они проверяют реальные переходы Session + IntakeController + Textual; ответы
моделей в тестах явно заменены тестовыми. Вызовы сервисов проверены отдельным
живым опытом выше.

Покрыты вопросы, собственный многострочный ответ, проверка ответов, исправление
плана, точное задание исполнителю, запуск только принятой версии, защита от
двойного запуска, изменившийся проект, восстановление черновика, режим чтения,
отмена в том числе до первого вызова модели, переполнение задания без потери
ответов, простой ответ без исполнения, старые сессии и экран 80×24.
Существующие проверки процессов, контрактов и режимов Jev тоже проходят.

CI запускает основной набор на Python 3.9 и 3.13, а затем повторяет независимые
CLI-проверки сохранённого калькулятора. CI не вызывает модели и не выдаётся за
новый живой прогон.
