# Калькулятор прибыли от криптосделки

Расчёт одной покупки и последующей продажи всего количества монет.
Требуется Python 3.9 или новее. Сеть и дополнительные пакеты не нужны.

В терминале из папки проекта выполните:

```sh
python3 crypto_profit.py
```

Введите цену покупки за монету, количество монет, цену продажи за монету
и отдельно комиссии покупки и продажи в процентах. Для нулевой комиссии
нажмите Enter. Дробные числа можно вводить через точку или запятую,
например `0.25` или `0,25`. Цена покупки и количество должны быть больше
нуля, цена продажи — неотрицательной, каждая комиссия — от 0% включительно
до 100% не включительно. При ошибке программа повторит запрос.
Ctrl+C или конец ввода отменяют расчёт.

Обе цены задаются вручную в одной валюте; результаты выражаются в ней же.
Комиссия покупки добавляется к затратам, комиссия продажи вычитается из
поступлений. Доходность = чистая прибыль / затраты с комиссией покупки × 100%.
Промежуточные суммы не округляются до копеек; вывод округляется до двух
знаков после запятой. Отрицательная чистая прибыль означает убыток.

## Пример

Покупка 2 монет по 100, продажа по 120, комиссия каждой операции 1%.
Введите последовательно `100`, `2`, `120`, `1`, `1`. Результат:

```text
Затраты на покупку с комиссией: 202,00
Поступления после продажи и комиссии: 237,60
Общая комиссия: 4,40
Чистая прибыль / убыток: 35,60
Доходность относительно затрат: 17,62%
```

Тот же пример одной командой:

```sh
printf '100\n2\n120\n1\n1\n' | python3 crypto_profit.py
```

Без комиссий прибыль составит `40,00`, доходность — `20,00%`:

```sh
printf '100\n2\n120\n\n\n' | python3 crypto_profit.py
```
