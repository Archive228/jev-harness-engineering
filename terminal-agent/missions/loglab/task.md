Исправь CLI LogLab — анализатор инцидентов из JSONL. Он должен превращать грязный поток событий в достоверную временную шкалу и два читаемых артефакта. Сейчас реализация содержит несколько ошибок: порядок времени, дубли, невалидные строки и уровни важности.

Прочитай README.md. Сохрани команду `python3 loglab.py INPUT --json REPORT.json --markdown REPORT.md` и описанный JSON-контракт. Исправь реализацию в нескольких файлах, добавь свои регрессионные тесты, запусти их. Создай `reports/incident.json` и `reports/incident.md` из `fixtures/incident.jsonl`; затем кратко объясни обнаруженные дефекты и результат.

Приёмку выполняет внешняя проверка на отдельных входах. Правильные exit codes, итоговые счётчики и фактические event_id важнее убедительного текста. Не представляй сервис с наибольшим числом ERROR как доказанную первопричину: это только кандидат для расследования. Без сторонних пакетов и сетевых запросов.
